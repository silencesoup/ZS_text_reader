# 本地剧情阅读器

一个安静的 Windows 桌面阅读器，从战双帕弥什 BWIKI 导入剧情，以角色名和单条对话逐句展示。没有立绘、背景图、音效或游戏风格装饰。

## 启动

- 本地剧情版：双击 `dist/阅览/阅览.exe`。整个文件夹可以移动，运行不需要安装 Python，也不需要再访问 E 盘的原始压缩包。更新后从托盘退出旧进程，再打开此程序。
- 源码版本：安装带 Tkinter 的 Python 3.10 或更新版本，双击 `start.bat`，或在本目录执行 `python reader.py`。没有第三方运行依赖。

## 使用

1. 左侧按剧情分类选择章节，再选择具体子章。搜索框按章节名称筛选。
2. 主窗口的阅读区域内，点击标题、角色名、正文或留白都可以看下一句，也可按 **空格 / → / Enter**；按 **←** 回到上一句。正文不可选中复制，长台词可以滚轮滚动。最后一句阅读完后再点一次，会继续下一小节；整章结束后继续同一分类的下一章。
3. 出现回应选项时，选择后阅读对应分支。通过“阅读记录”回到选项，可重新选择另一条路线。
4. 阅读位置、选项、字号和配色自动保存。再次启动会恢复上次阅读。
5. **Ctrl+B** 收起或展开目录；**Ctrl+H** 打开阅读记录。右上角调整字号和深浅色。
6. 点击“下载本章”缓存当前章节的全部子章。列表中的 **●** 表示已下载，**○** 表示尚未下载。已下载的内容可以断网阅读。
7. “更新目录”重新读取最新章节目录；“导入链接”支持单个章节或具体关卡链接。底部“来源 · BWIKI”打开当前剧情原网页。
8. 点击右上角 **“悬浮阅读”**：主窗口隐藏，桌面上方仅显示置顶的台词浮层，任务栏和 Alt+Tab 中不显示该浮层，程序驻留右下角托盘。默认使用透明背景，鼠标移入才显示控制栏。
9. 浮层顶部控制栏之外的整个阅读区域（包括透明留白），点击都进入下一句，正文不可选中复制。移动浮层请拖动顶部 **“拖动移动”** 区域。对话选项单独执行选择，未选择回应时不会跳过。右键可返回上一句、切换下一节、调整字号、宽度、透明度及文字颜色；长台词可滚轮滚动。浮窗和主窗口共用进度，连读下一节会从该节开头开始；手动选节会恢复该节的上次进度。
10. 鼠标移入浮窗，点击 **“章节”**（或右键 **“选择大小章节”**），即可在小面板内选择剧情分类、大章节和小节，无需打开主窗口。支持搜索大章节，双击小节或点击“阅读所选小节”开始。
11. **主窗口右上角的 × 会收起到托盘，不会退出程序。** 浮窗“收起”也会隐藏浮窗，保留托盘图标。双击托盘图标恢复主窗口，右键可显示/隐藏浮窗、选章节或 **“退出程序”**。图标可能位于 Windows 右下角的 **^** 折叠区。
12. 浮窗顶部提供 **上一节 / 本节从头 / 下一节 / 字号＋ / 字号－**。切节从目标小节首句开始，跨章节时沿当前剧情类型选择；“本节从头”回到当前小节第一句并清除本节的回应选择，其他小节进度保留。主窗口也有“本节从头”按钮。控制栏在窄浮窗内自动换行，鼠标移入后按钮的整个矩形范围均可点击。
13. 主窗口底部或浮窗右键菜单打开 **“热键设置”**，分别设置“上一个对话 / 下一个对话”，默认为 **← / →**。点击输入框后按下新按键，可使用 Ctrl / Alt / Shift / Win 组合键，保存后自动记住。下一句与点击正文执行同一个动作，遇到未选择的回应会等待选择。主窗口中仍可用空格 / Enter 进入下一句；若将它们设为上一句，则按新配置执行。
14. 默认勾选 **“浮窗显示时，在其他软件中也可使用热键”**。浮窗显示时所选按键由阅读器使用，收起或返回主窗口后释放；选章节、操作浮窗菜单、修改热键时暂停。可取消勾选，改为仅在阅读器获得键盘焦点时生效。按键被其他程序占用时会提示，请改用其他组合键。

连续阅读沿当前剧情类型进行，例如普通剧情结束后继续下一章普通剧情，不会自动跳进隐藏剧情。分类读完、下一章缺少同类型小节，或联网加载失败时会停下并提示；失败时保留当前句，稍后再点可重试。对话选项需要先选择回应，才会继续。

当前可离线阅读 2,146 个小节。已从 138 个本地配音包补充 2,072 个小节，原有 74 个网页缓存保持不变；包内包含主线第 1～43 章、浮点纪实、外篇、间章等内容。不同版本的拆句、章节命名和勘误存在差别，未在本地包中匹配到的 WIKI 条目仍显示未下载。具体范围见 `data/offline-download-report.json`。

### 从本地配音包导入

`local_archive_import.py` 直接读取 ZIP 中的 `台词音频索引.csv` 和 `pack.json`，不解压音频，也不修改源压缩包。CSV 用于核对角色、正文及编号；实际阅读使用 `pack.json` 的完整文本与明确的选项跳转，保留未配音的旁白、动作和标点台词。重复的“当前画面定位”书签不作为新小节导入，条件路线保留为独立入口。

```powershell
python local_archive_import.py "本地压缩包总目录" --apply
```

只验证元数据时省略 `--apply`；只生成待导入缓存时使用 `--stage`。导入工具仅依赖 Python 标准库。已有网页正文和阅读进度保留，替换目录前会备份至 `data/local-import/before-local-import.zip`；验证与对照结果保存在同一目录中。循环问答菜单按原跳转读取，再次进入菜单时会重新等待选择。选项较多时，主窗口和浮窗均支持分页。

### 全量离线导入

`offline_import.py` 使用公开批量接口建立小节清单、下载原文，再转换为阅读器缓存。它保留断点，已有原文不重复下载，嵌套对话选项保持分支；不支持的特殊模板回退到原网页解析。每次网络请求至少间隔 10 秒，收到明确的安全策略拦截（HTTP 567）立即停止，不自动重试。

批量导入工具需要额外的解析库，阅读器本身不需要：

```powershell
python -m pip install -r requirements-import.txt
python offline_import.py
```

重新运行同一命令可以接着未完成的下载。仅整理已取得的数据、不访问网络时，执行 `python offline_import.py --cache-only`。原文断点保存在 `data/offline-source/`；完成情况和缺失小节见 `data/offline-download-report.json`。生成的缓存会补充到现有打包版本的 `data/cache/`，不改动阅读进度。

本次全量下载已取得 238 个目录条目对应的目录快照，以及网站语义接口列出的 3,660 个剧情小节清单；正文下载遇到站点安全策略拦截，**尚未完成全量离线**。请以报告里的 `complete_chapters` 和各章的 `downloaded/total` 判断完整度；有小节目录不代表已取得正文。

## 数据与网络

源码版数据在项目 `data/` 中；打包版数据在 `阅览.exe` 同级的 `data/` 中。

- `data/cache/`：目录、子章列表及剧情正文的 JSON 缓存。
- `data/progress.json`：阅读进度和界面设置。备份此文件及缓存目录即可保存阅读记录。
- `data/reader.log`：网络或解析失败的诊断日志。

首次读取未缓存的章节或关卡需要联网。导入只获取公开网页文本，不下载图片、音频或视频，也不会登录账号。整章下载逐页进行，新页面之间间隔两秒，已有缓存会跳过；遇到网站限流会暂停，请稍后再试。

目前按 BWIKI 的 `zs-clist` 子章列表、`zs-DialogBox` 对话、`TabContainer` 选项结构导入；已验证序章、第一章及较新主线关卡。部分特殊活动或未收录页面可能采用不同结构，会显示导入失败，不能保证所有目录条目均已适配。

目录里的网站未创建条目会略过。对话选项保留分支，隐藏的模板备份不会重复导入；旁白和战斗情境保留为文字。台词按原网页的一条对话展示，不按标点拆分。

剧情来源：[战双帕弥什 BWIKI · 剧情回顾](https://wiki.biligame.com/zspms/剧情回顾)。游戏剧情及 WIKI 整理内容的权利归原权利人，程序保留各关卡来源链接。

```powershell
python -m unittest discover -s tests -v
python -m py_compile reader.py reader_core.py
```

可选打包：安装 PyInstaller 后执行 `python -m PyInstaller --noconfirm --windowed --onedir --name 阅览 reader.py`。随后将需要离线携带的 `data/cache/` 复制到 `dist/阅览/data/cache/`。请保留整个输出文件夹。
